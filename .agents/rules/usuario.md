# Regra de Escopo - Usuário

Neste projeto FrontEnd-RF, todas as alterações devem ser restritas exclusivamente à parte de **Usuário** (comprador / artesão / pessoa física), abrangendo:
- Telas de usuário: `DashboardUsuario.tsx`, `RegisterUser.tsx`
- Hooks e integrações de usuário: `useLoggedUser.ts`, endpoints e tipos de usuário em `Axios.ts`
- É expressamente proibido modificar módulos de Empresa ou partes não relacionadas ao Usuário.
