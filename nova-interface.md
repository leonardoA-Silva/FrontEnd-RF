# Nova interface do Reaproveita Franca

## Objetivo
Atualizar a linguagem visual de todas as páginas para uma plataforma de economia circular local, preservando rotas, conteúdo essencial e fluxos.

## Plano
- [ ] Definir tokens e direção no `DESIGN.md` → revisar paleta floresta/creme, tipografia, layout e animações.
- [ ] Criar base visual global responsiva, foco acessível e suporte a `prefers-reduced-motion` → validar classes e estados comuns.
- [ ] Redesenhar experiência pública (início, login e escolha de perfil) → validar rotas e ações.
- [ ] Unificar formulários de cadastro, modal, notificações, dashboards e mapa → validar controles e navegação existentes.
- [ ] Executar `npm run lint` e `npm run build` → ambos finalizam sem erros.

## Direção
Tons botânicos e materiais locais como couro e madeira; hero editorial assimétrico, superfícies de papel creme e áreas de destaque em floresta. Animações mais presentes, mas curtas e funcionais.

## Concluído quando
- Todas as rotas existentes compartilham a identidade visual sem alterar guards ou fluxos.
- Layout permanece utilizável em telas pequenas, com foco visível e movimento reduzido respeitado.
- Lint e build passam; nenhuma alteração é commitada.
