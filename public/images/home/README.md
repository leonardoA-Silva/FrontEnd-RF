# Home visual assets

These original assets were generated with the built-in image generation tool for the selected home reference, then encoded as local WebP files. No external image service is contacted at runtime.

- `hero.webp`: intertwined cognac leather, cream woven textile and olive EVA loop on a transparent background. Final prompt: remove only the studio background, retain material geometry, cutouts and translucent ground shadow.
- `transformation.webp`: offcuts → separated bag panels → completed tote. Final prompt: remove only the warm-white studio background, preserving all three stages, connecting thread and shadows.
- `materials.webp`: wide studio composition of sculptural cognac leather, natural woven linen and stacked olive/charcoal EVA against dark forest green. No text or logos.

Images illustrate reuse possibilities, not real listings, measured impact or available inventory. The interactive scene uses locally generated geometry and procedural grain/weave bump maps, rather than claiming the generated illustration is a true 3D model. UI logo is a local SVG in `Brand.tsx`; no social accounts are invented.
